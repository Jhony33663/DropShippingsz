# DropS-Scalanze: Sistema de Inteligencia y Dropshipping en Quito

Sistema integrado para investigación de mercado, análisis de competidores mayoristas en Quito y cálculo de viabilidad de productos bajo el modelo de Pago Contra Entrega (COD) en Ecuador.

---

## 🏍️ Módulo Especializado: Nicho Panas Bikers (Quito & Ecuador)

Adaptación completa del pipeline de inteligencia y economía unitaria para el sector de repuestos y accesorios de motocicletas:

* 🌐 **[dashboard-panas-bikers.html](file:///B:/DropShippingsz/dashboard-panas-bikers.html)**: Dashboard interactivo con tema oscuro y naranja neón, matriz de productos ganadores (Deal Scores), radar de tiendas moteras en Quito, swipe file de reels virales y simulador financiero unitario.
* 🐍 **[market_intelligence_panas_bikers.py](file:///B:/DropShippingsz/market_intelligence_panas_bikers.py)**: CLI especializado para análisis de márgenes, ranking motero y ganchos de 3 segundos contra el dolor del biker quiteño.
* 📘 **[docs/estudio-mercado-panas-bikers-quito.md](file:///B:/DropShippingsz/docs/estudio-mercado-panas-bikers-quito.md)**: Estudio competitivo de tiendas moteras en Quito (@tiendamoteraec, @motosquito, @procircuit_ec) y brechas de mercado.
* 📘 **[docs/estrategia-emocional-panas-bikers-quito.md](file:///B:/DropShippingsz/docs/estrategia-emocional-panas-bikers-quito.md)**: Los 5 disparadores emocionales del motero andino (robo en veredas, niebla Papallacta, daño OIS celular, fracturas de tobillo, aceite adulterado).
* 📘 **[docs/indagacion-mejores-contenidos-panas-bikers.md](file:///B:/DropShippingsz/docs/indagacion-mejores-contenidos-panas-bikers.md)**: Minería de comentarios ecuatorianos, pruebas de tortura ASMR y swipe file de guiones para Reels/TikTok.
* 📘 **[docs/playbook-operativo-panas-bikers-quito.md](file:///B:/DropShippingsz/docs/playbook-operativo-panas-bikers-quito.md)**: Logística express en Quito con motorizados, protocolo antifraude WhatsApp y cobro contra entrega (<8% devoluciones).

## Comandos Rápidos del CLI Panas Bikers

```bash
# Ver catálogo ganador biker con Deal Scores y márgenes netos
python market_intelligence_panas_bikers.py --catalog

# Radar de competidores y tiendas moteras en Quito
python market_intelligence_panas_bikers.py --stores

# Swipe file de hooks virales de 3 segundos
python market_intelligence_panas_bikers.py --hooks

# Análisis financiero de un producto específico (botas, candado, exploradoras, soporte, etc.)
python market_intelligence_panas_bikers.py --product botas
python market_intelligence_panas_bikers.py --product candado
python market_intelligence_panas_bikers.py --product exploradoras
```
